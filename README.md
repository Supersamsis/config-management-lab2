# Визуализатор графа зависимостей npm (ПР2, Вариант 12)

Разработан инструмент для анализа и визуализации графа зависимостей пакетов JavaScript (npm). 
Программа строит дерево зависимостей (с учетом транзитивности), находит обратные зависимости 
и генерирует изображение графа с помощью Graphviz.

## Установка и зависимости

Для работы программы требуется Python 3.11+ и установленный Graphviz (для генерации картинок).

Установка Python-зависимостей:
py -3.11 -m pip install -r requirements.txt

## Запуск

Запуск в режиме реального репозитория (npm):
py -3.11 -m src.main --package express --version 4.18.2 --ascii-tree

Запуск в тестовом режиме (используя файл-описание графа):
py -3.11 -m src.main --package A --test-mode --repo examples/test_graphs/graph1.txt --ascii-tree

Поиск обратных зависимостей:
py -3.11 -m src.main --package A --test-mode --repo examples/test_graphs/graph3.txt --reverse G

## Параметры командной строки

- `--package` (обязательный) — имя анализируемого пакета.
- `--repo` — URL репозитория или путь к файлу тестового репозитория.
- `--test-mode` — включить режим работы с тестовым файлом графа.
- `--version` — версия пакета (по умолчанию `latest`).
- `--ascii-tree` — вывести дерево зависимостей в консоль.
- `--filter` — подстрока для исключения пакетов из анализа.
- `--reverse` — найти пакеты, которые зависят от указанного.

## Сравнение с выводом реального менеджера пакетов (npm ls)

Если сравнить работу нашего визуализатора с командой `npm ls` (штатным инструментом), можно заметить следующие отличия:

1. **Дедупликация:** В реальном `npm ls` используется "поднятие" (hoisting) зависимостей. Если пакетам `A` и `B` нужен один и тот же пакет `C`, `npm` покажет его на верхнем уровне один раз, чтобы не дублировать. Наш алгоритм обхода (DFS) строит строгое дерево, поэтому пакет `C` может отображаться в ветках `A` и `B` отдельно.
2. **Формат вывода:** `npm ls` выводит текстовое иерархическое дерево. Наш инструмент, помимо текста, генерирует направленный граф в формате Graphviz (картинку), где зависимости показаны в виде связей между узлами.
3. **Обработка циклов:** В npm циклические зависимости (хоть это и плохая практика) отображаются особым образом. Наш визуализатор явно помечает цикл текстом `[Цикл: Имя_пакета]`, чтобы не уйти в бесконечную рекурсию.
